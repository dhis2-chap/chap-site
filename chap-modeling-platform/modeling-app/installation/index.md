# Installing Chap Core for use with the DHIS2 Modeling APP

This guide covers installing and running Chap Core using Docker Compose. This is necessary if you want to run the modeling app.

Warning

We highly recommend you to have read the [recommendation for server deployment](https://chap.dhis2.org/chap-modeling-platform/modeling-app/running-chap-on-server/index.md) before installing Chap Modeling Platform on a server.

## Choose Your Installation Path

First-time Setup (New Users)

Installing Chap Core for the first time? Follow the [First-time Setup guide](https://chap.dhis2.org/chap-modeling-platform/modeling-app/fresh-installation/index.md).

Updating to a New Version

Already have Chap Core installed and want to upgrade to a newer version? Follow the [Update guide](https://chap.dhis2.org/chap-modeling-platform/modeling-app/upgrading-installation/index.md).
